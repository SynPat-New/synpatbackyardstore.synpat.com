CUSTOM POST TYPES
=================

TAXONOMIES
==========
- tech_sector              Technology categorization

AJAX ACTIONS
============
- add_to_wishlist          Add portfolio to wishlist
- remove_from_wishlist     Remove from wishlist
- save_tech_preference     Save customer preferences
- load_portfolio_patents   Load patents for portfolio
- test_ci_connection       Test CodeIgniter DB connection
- start_data_migration     Migrate data from CI

===========
- Patent Store Dashboard

KEY BUSINESS FIELDS
===================
Portfolios:
- n_patents        Number of patents
- essnt           Essential status flag  
- n_lic           Number of licensees
- u_upfront       Upfront payment amount

Patents:
- patent_identifier        Patent number
- filing_timestamp        Filing date
- grant_timestamp         Grant date
- expiry_timestamp        Expiration date
- enforcement_status      Legal status
- cited_by_count         Forward citations
- cites_prior_count      Backward citations
- independent_claims     Claims count

INSTALLATION REQUIREMENTS
=========================
- WordPress 5.0+
- PHP 7.4+
- MySQL 5.6+

SECURITY FEATURES
=================
- Nonce verification on all AJAX
- Prepared statements for SQL
- Output escaping (esc_html, esc_attr)
- Input sanitization
- Capability checks
- ABSPATH protection
